Cruce de capas

Cada capa base (sensores remotos, catastro y calidad del aire) se lleva a una escala común de 0 a 1 y se levanta en picos: la altura es el valor y el color es el de su mapa original. Las capas se cruzan con operaciones simples para producir siete índices; dos de ellos se cruzan otra vez para dar los índices compuestos.
